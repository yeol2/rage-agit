# 랜딩페이지 (히어로) 설계 문서

## 배경 및 목적

[2026-08-03-clan-scrim-dashboard-design.md](2026-08-03-clan-scrim-dashboard-design.md)에서 정의한 클랜 내전 대시보드 MVP의 진입 지점이 되는 랜딩페이지를 만든다. 방문자가 클랜 대시보드로 바로 이동하도록 유도하는 것이 유일한 목적이며, 클랜/서비스 소개 등 다른 목적은 이번 범위에 넣지 않는다.

디자인은 [mapleaudit.com](https://www.mapleaudit.com/)의 톤(다크 테마, "내 OO, 직접 확인하자" 형태의 헤드라인, 심플한 상단 네비게이션)을 참고하되, 배경에 PUBG 게임 테마에 맞는 3D 포인트클라우드 시각 효과를 추가해 차별화한다.

## 컬러 팔레트

- 배경: `#0E0B13`
- 포인트 컬러(주): `#FF9233`
- 포인트 컬러(보조, 가끔 사용): `#C49520`
- 텍스트(주요): `#FFFFFF`
- 텍스트(보조, 중요도 낮은 숫자 등): `#322F36`

## 페이지 구성

단일 페이지, 풀스크린 히어로 하나로 구성한다. 다른 섹션(프로세스 소개, 클랜 소개 등)은 이번 범위에 넣지 않는다.

**상단 네비게이션 바**
- 좌측: 클랜 로고 (교체 가능한 이미지 슬롯 — 로고 파일은 나중에 바뀔 수 있으므로 하드코딩하지 않고 컴포넌트/설정으로 분리)
- 우측: "대시보드" 링크

**히어로 영역**
- 배경: 3D 포인트클라우드 (아래 "배경 3D 효과" 참고)
- 중앙 정렬 콘텐츠:
  - 클랜명: "RAGE"
  - 슬로건: "내 우승확률, 직접 확인하자."
  - CTA 버튼: "대시보드 보기" (포인트 컬러 `#FF9233` 강조, 호버 시 밝기 변화)
- 텍스트 가독성을 위해 포인트클라우드 배경 위에 어두운 그라디언트/비네트 오버레이를 깐다.
- 반응형: 모바일에서도 레이아웃이 깨지지 않아야 한다.

## 배경 3D 효과 (이미지 기반 포인트클라우드)

사용자가 제공한 에란겔 맵 이미지(`public/images/erangel-hero-source.jpg`)를 소스로 사용해 3D 포인트클라우드를 생성하고 자동 회전시킨다.

**변환 절차**
1. 소스 이미지를 그레이스케일 밝기맵으로 변환한다.
2. 이미지를 촘촘한 그리드(예: 150×150 포인트)로 다운샘플링한다. 각 포인트의 x/y는 그리드 위치, z(높이)는 해당 픽셀의 밝기값을 기반으로 매핑한다 — 밝은 영역(건물, 안테나, 물빛 반사 등)은 높게, 어두운 영역은 낮게 배치해 대략적인 입체감을 연출한다. 이는 실제 지형 고도 데이터가 아니라 이미지 밝기를 이용한 근사치다.
3. 포인트 색상은 초록 계열 그라디언트로 통일하고, 밝기값에 따라 명도를 달리해 "홀로그램 지형 스캔"처럼 보이게 한다.
4. react-three-fiber로 포인트클라우드를 렌더링한다.
5. 카메라를 살짝 내려다보는 각도로 고정하고, `useFrame` 훅으로 Y축 기준 천천히 자동 회전시킨다 (정적 이미지가 아니라 계속 회전).
6. 포인트 크기/투명도를 조절해 홀로그램 느낌을 강화한다.

## 기술 스택

- Next.js (기존 프로젝트 스택 유지)
- react-three-fiber + Three.js — 3D 포인트클라우드 렌더링
- Tailwind CSS — 레이아웃/반응형 스타일링

내전 데이터 수집/대시보드 백엔드 스택(Spring Boot/Kotlin 여부 등)은 이 랜딩페이지 스펙과 무관하며, 별도 논의·별도 스펙 대상이다.

## 향후 확장 (이번 스코프 아님)

- 프로세스 설명, 클랜 소개 등 추가 섹션
- 로고 실제 파일 교체
- 3D 효과의 실제 지형 고도 데이터 기반 정밀화

## 알려진 리스크 / 미확정 사항

- 밝기 기반 높이 매핑 파라미터(그리드 해상도, 높이 배율, 회전 속도, 포인트 크기)는 실제 렌더링 결과를 보면서 튜닝이 필요하다.
- 저사양 기기에서 3D 렌더링 성능 이슈가 있을 경우 포인트 수를 줄이거나 정적 폴백을 고려해야 할 수 있다 (이번 스펙에서는 최적화 전략을 확정하지 않는다).
