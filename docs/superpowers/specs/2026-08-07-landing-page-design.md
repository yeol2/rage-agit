# 랜딩페이지 설계 문서

> 2026-08-07 갱신. 초안에 있던 "중앙 정렬 + 3D 포인트클라우드 배경 + 히어로 단독" 구성은
> 실제 디자인 확정 과정에서 바뀌었다. 이 문서는 현재 구현을 기준으로 다시 쓴 것이다.

## 배경 및 목적

[2026-08-03-clan-scrim-dashboard-design.md](2026-08-03-clan-scrim-dashboard-design.md)에서 정의한 클랜 내전 대시보드 MVP의 진입 지점이 되는 랜딩페이지를 만든다. 방문자가 클랜 대시보드로 이동하도록 유도하는 것이 주 목적이고, 어떤 기능이 준비돼 있고 무엇이 준비 중인지 알리는 것이 부차 목적이다.

디자인 톤은 [mapleaudit.com](https://www.mapleaudit.com/)을 참고한다 — 다크 테마, "내 OO, 직접 확인하자" 형태의 대비 헤드라인, 좌우 여백이 있는 문서형 레이아웃, 모노스페이스 HUD 라벨.

## 브랜드

**사이트명**: `RAGE AGIT` (클랜명은 `RAGE`)

**컬러 팔레트**

| 용도 | 값 | 비고 |
|---|---|---|
| 배경 | `#0E0B13` | |
| 포인트(주) | `#FF9233` | CTA 버튼, 아이브로우, 헤드라인 강조 |
| 포인트(보조) | `#C49520` | 가끔 사용 — 현재는 `COMING SOON` 배지 |
| 텍스트(주요) | `#FFFFFF` | |
| 텍스트(보조) | `#322F36` | 큰 번호(01·02·03), 헤드라인 첫 줄 |
| 메뉴 텍스트 | `#A0A0A2` | 상단 네비게이션 항목, HUD 라벨 |
| 증가 표시 | `#4ADE80` | 클랜원 주간 증가분 |

**폰트**: Pretendard Variable (npm `pretendard` 패키지로 자체 호스팅, dynamic subset). 폴백은 Apple SD Gothic Neo → Malgun Gothic → system-ui. HUD 라벨은 시스템 모노스페이스에 `letter-spacing: 0.18em` + 대문자.

**로고**: 언제든 교체 가능해야 하므로 `siteConfig.logo.src`로 분리한다. 값이 비어 있으면 주황 다이아몬드 마크로 폴백한다. 실제 로고 파일은 아직 저장소에 없다.

## 페이지 구성

단일 페이지. 모든 콘텐츠는 최대 폭 `1200px` 중앙 컨테이너 안에 들어가며, 좌우 여백은 모바일 `20px` / `sm` 이상 `32px`이다.

### 상단 네비게이션

- 좌측: 로고 + `RAGE AGIT`, 구분선, `PROTOCOL: V.0.4.21` (`lg` 이상에서만 표시)
  아래 줄: 주황 점 + `SYSTEM ONLINE // SERVER: ASIA-SEOUL`
- 중앙: `DASHBOARD` `MEMBERS` `MATCHES` `RANKINGS` — 13px, `#A0A0A2`.
  해당 페이지가 아직 없으므로 링크가 아니라 `aria-disabled` 상태이며,
  스크린리더에는 "(준비 중)"이 함께 읽힌다.
- 우측: 모서리가 잘린 박스 안에 `LOCAL TIME` + 실시간 시계.
  시계는 클라이언트 컴포넌트이고, 서버 렌더 시점에는 `--:--:--`를 표시해 hydration 불일치를 피한다.

로그인은 없다. 사용자 인증을 암시하는 표시를 두지 않는다.

### 히어로

- 아이브로우 행: `VICTORY ANALYTICS`(주황) — 가로 실선 — `● LIVE · CLAN SCRIM`(`sm` 이상에서만 표시)
- 헤드라인 (좌측 정렬, 모바일 48px / `md` 이상 72px)
  - 1행 `내 우승확률,` — `#322F36`
  - 2행 `직접`(흰색) + `확인하자.`(주황). **밑줄 없음.**
- 본문: 카카오 계정 등록만으로 무엇을 볼 수 있는지 2문장
- 클랜원 수: `CLAN MEMBERS` 라벨 + 총원 + `+N 이번 주`(초록). 매주 갱신한다.
- CTA: `대시보드 보기 →` (주황 배경, 우하단 모서리 잘림, 호버 시 밝기 상승)

### 기능 섹션

`PLATFORM FEATURES` 아이브로우 + 가로 실선, 제목 `클랜 운영에 필요한 모든 것`, 그 아래 6행 목록.
각 행은 큰 번호(`01`~`06`, `#322F36`) + 제목 + 설명으로 구성한다.

| # | 항목 | 상태 |
|---|---|---|
| 01 | 자동 매치 집계 | 예정 범위 |
| 02 | 클랜원 대시보드 | 예정 범위 |
| 03 | 랭킹 시스템 | 예정 범위 |
| 04 | 실시간 리더보드 | `COMING SOON` |
| 05 | 방송 오버레이 | `COMING SOON` |
| 06 | 디스코드 연동 | `COMING SOON` |

01~03은 MVP 범위이고 04~06은 그 이후다. 미구현 항목은 불투명도를 낮추고 `COMING SOON` 배지를 붙인다. 블러는 쓰지 않는다 — 렌더링 오류처럼 보인다.

## 콘텐츠 분리 원칙

카피, 네비게이션 항목, 클랜원 수, 기능 목록은 전부 `lib/siteConfig.ts` 한 곳에 둔다. 문구를 바꾸려고 컴포넌트를 열 일이 없어야 한다.

**표시하는 수치는 실제 값이어야 한다.** 디자인을 채우기 위한 가짜 통계는 넣지 않는다.

## 기술 스택

- Next.js 14 (App Router, TypeScript)
- Tailwind CSS — 팔레트와 `max-w-shell`(1200px)을 테마 토큰으로 정의
- Pretendard (npm 자체 호스팅)

## 반응형 기준

| 폭 | 동작 |
|---|---|
| ~640px | 헤드라인 48px, 기능 행 세로 배치, 네비 2줄 줄바꿈, `LIVE` 상태 라벨 숨김, 좌우 여백 20px |
| 640px~ | 상태 라벨 표시, 좌우 여백 32px |
| 768px~ | 헤드라인 72px, 기능 행 가로 배치 |
| 1024px~ | `PROTOCOL` 라벨 표시 |
| 1200px~ | 컨테이너 고정 폭, 중앙 정렬 |

어느 폭에서도 가로 스크롤이 생기지 않아야 한다.

## 알려진 미해결 사항

- `public/images/erangel-hero-source.jpg`는 포인트클라우드 배경용으로 넣었으나 현재 코드에서 쓰이지 않는다. 배경 작업을 재개할 때까지 남겨둔다.
