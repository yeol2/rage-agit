# 랜딩페이지

> [빅뱅배포.md](../../빅뱅배포.md)의 초기 배포 범위 중 하나. 실제 구현 상태 기준으로 작성했다 — 최초 설계안과 달라진 부분은 아래에 명시했다.

## 목적

방문자가 클랜 대시보드로 이동하도록 유도하는 단일 페이지. 로그인 없음.

## 최초 설계안과 달라진 것

원래 설계(2026-08-07 첫 브레인스토밍)는 **히어로 배경에 회전하는 3D 포인트클라우드**(react-three-fiber로 PUBG 맵 이미지를 초록 점으로 렌더링)를 핵심 아이디어로 잡았었다. 실제로 SDD로 구현까지 완료했었지만(포인트클라우드 배경 회전, Task 5까지 리뷰 통과), 브라우저 수동 검증 중 **사용자가 "너무 오래 걸린다"며 작업 전체를 취소**했고, 이후 mapleaudit.com 스타일 참고 스크린샷을 기반으로 직접 다시 만들면서 **포인트클라우드 배경은 최종 결과물에서 빠졌다**. 지금 히어로는 단색 배경(`#0E0B13`)이다.

`public/images/erangel-hero-source.jpg`(포인트클라우드 소스로 준비했던 에란겔 맵 이미지)는 저장소에 남아있지만 현재 코드에서 쓰이지 않는다. 배경 작업을 재개하면 그때 다시 쓴다.

발전소 지역을 포인트클라우드로 재구성하는 실험(`prototypes/powerplant-pointcloud.html`)도 별도로 만들었으나, 이는 랜딩페이지 배경과는 무관한 독립 프로토타입으로 마무리하지 않고 보류 상태다.

## 브랜드

**사이트명**: `RAGE AGIT`

| 용도 | 값 |
|---|---|
| 배경 | `#0E0B13` |
| 포인트(주) | `#FF9233` |
| 포인트(보조) | `#C49520` — `COMING SOON` 배지 등에 사용 |
| 텍스트(주요) | `#FFFFFF` |
| 텍스트(보조, 큰 번호 등) | `#322F36` |
| 메뉴/HUD 라벨 | `#A0A0A2` |
| 증가 표시(클랜원 +N) | `#4ADE80` |

**폰트**: Pretendard Variable, npm 패키지로 자체 호스팅. 워드마크(`RAGE AGIT` 로고 텍스트)는 굵게(`font-bold`) + 자간 좁게(`tracking-tight`)로 참고 로고 이미지의 느낌을 맞췄고, 나머지 HUD 라벨(네비 메뉴, `LOCAL TIME` 등)은 모노스페이스 + 넓은 자간(`letter-spacing: 0.18em`, 대문자)을 쓴다.

**로고**: `siteConfig.logo.src`가 비어있으면 주황 다이아몬드 마크로 폴백. 실제 로고 파일은 아직 없다.

## 페이지 구성 (실제 컴포넌트 기준)

`app/page.tsx` = `<Nav /> <Hero /> <Features /> <Footer />`

**Nav** (`components/Nav.tsx`)
- 좌측: 로고 + `RAGE AGIT`
- 중앙: `DASHBOARD`(활성, `/dashboard`로 링크) · `MEMBERS`/`MATCHES`/`RANKINGS`(비활성, `aria-disabled` + 스크린리더용 "(준비 중)")
- 우측: 실시간 로컬 시계 (`LocalClock`, 1초마다 갱신, `'use client'`)
- `siteConfig.nav[].ready`가 `true`인 항목만 실제 `Link`로 렌더링한다.

**Hero** (`components/Hero.tsx`)
- 아이브로우: `VICTORY ANALYTICS` — 가로선 — `● LIVE · CLAN SCRIM`(`sm` 이상에서만)
- 헤드라인 3단 색상: `내 우승확률,`(muted) / `직접`(흰색) `확인하자.`(주황, 밑줄 없음)
- 본문 2문장
- 클랜원 수: `클랜원 469명 +12 이번 주`(초록) — `siteConfig.members`에서 가져옴, 매주 수동 갱신
- CTA: `대시보드 보기 →`

**Features** (`components/Features.tsx`)
- `PLATFORM FEATURES` — `클랜 운영에 필요한 모든 것`
- 6개 항목, 번호(01~06) + 제목 + 설명. `ready: true`인 01~03(자동 매치 집계/클랜원 대시보드/랭킹 시스템)은 정상 표시, `ready: false`인 04~06(실시간 리더보드/방송 오버레이/디스코드 연동)은 흐리게 + `COMING SOON` 배지.

**Footer** (`components/Footer.tsx`)
- 좌측: 사이트명 + 설명 문구(마지막 문장만 포인트 컬러 강조: "감이 아니라 기록입니다.") + API 출처 표기
- 우측: 링크 4개, Nav와 같은 `ready` 규칙
- 하단: 저작권 연도(자동 계산) + `VERSION` (`package.json`의 버전을 직접 읽음, 하드코딩 아님)

## 콘텐츠 분리 원칙

카피, 네비게이션 항목, 클랜원 수, 기능 목록은 전부 `lib/siteConfig.ts` 한 곳에 있다. 컴포넌트를 열지 않고 문구만 바꿀 수 있어야 한다는 원칙을 지켰다.

## 반응형

375 / 768 / 1024 / 1440px에서 가로 스크롤 없음을 확인했다. 640px 미만에서는 헤드라인이 작아지고(48px), 상태 라벨이 숨겨지고, 네비가 줄바꿈된다.

## 확인된 작지 않은 버그 (수정 완료)

- **Pretendard 폰트 이름만 있고 실제로 로드되지 않던 문제** — CSS `font-family`에 이름만 적어놓으면 로드되는 게 아니다. `@import`로 실제 웹폰트 CSS를 불러와야 한다.
- **`npm run dev` 중에 `npm run build`를 돌리면 `.next` 산출물이 꼬여 CSS 전체가 깨짐** — dev 서버가 떠 있을 때는 build를 돌리지 않는다.
